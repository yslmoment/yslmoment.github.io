# Publication figures

Homepage previews share a 16:10 image frame and a uniform caption footer.
Wide figures use `object-fit: contain`; the FAGEN poster and golf-swing figure
use a display-only `object-fit: cover` crop. All source images remain unchanged,
and preview links open the complete paper, poster, or project page.

- `icoa-overview.png`: original teaser from the author's ICoA project page,
  https://yslmoment.github.io/ICoA/teaser.png (1293 × 431 pixels).
  Associated paper: *Will the User Ever Know? Covert Indirect Prompt Injection
  Attacks on Tool-Using LLM Agents*, EMNLP 2026 Main Conference.
  Downloaded unchanged; display with `object-fit: contain` so neither comparison
  panel is cropped.

- `fagen-poster.png`: full-page preview of the author's ICML 2026 FAGEN poster,
  https://damilab.github.io/images/publications/pdf/covert-ipi-fagen-icml2026-poster.pdf.
  Associated paper: *What Did You Do Behind My Back?! Covert Indirect Prompt
  Injection on Tool-Using LLM Agents*. Rendered from page 1 with PyMuPDF at
  805 × 1200 pixels, without cropping or altering the source poster. The homepage
  preview crops the display; both the thumbnail and the Poster PDF link open the
  original PDF for readable detail.

- `golf-swing.png`: Figure 1 (overall framework) from *Explainable Graph-Based
  Golf Swing Analysis Integrating Club and Body Keypoints for Ball Flight
  Outcome Prediction*, Seunghyeon Jung et al., Applied Sciences 16(8), 3813
  (2026), https://doi.org/10.3390/app16083813.
  Source: https://damilab.github.io/images/publications/golf-swing.png.
  Downloaded unchanged (685 × 678 pixels), including the original figure
  caption; the homepage uses a cropped preview. Copyright © 2026 by the
  authors, licensed under CC BY 4.0: https://creativecommons.org/licenses/by/4.0/.
