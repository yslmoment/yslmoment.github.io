PROJECT 2025.04 – 현재Present · DAMILAB × 기상청 (KMA)Korea Meteorological Administration (KMA)

기상위성 GK2A 지표면 온도(LST) 고해상화 LST Super-Resolution from KMA's GK2A Satellite

기상청과의 협업 과제. 정지궤도 위성 GK2A의 2km 해상도 지표면 온도(LST)를 250m로 다운스케일링하는 Guided Depth Super-Resolution 연구.

A KMA collaboration. Downscaling Land Surface Temperature (LST) from the geostationary GK2A satellite from 2km to 250m via Guided Depth Super-Resolution.

개요Overview

기상청(KMA)과 협업하는 다년간 과제로, 정지궤도 기상위성 GK2A로부터 추출한 지표면 온도(Land Surface Temperature, LST)를 250m 해상도로 고해상화하는 것이 목표입니다. GK2A의 native 해상도(2km)와 농업·도시 모니터링 등 응용에 필요한 해상도(250m) 사이의 domain gap을 ML 기반 super-resolution으로 좁히는 연구입니다.

A multi-year collaboration with KMA aiming to super-resolve Land Surface Temperature (LST) retrieved from GK2A, KMA's geostationary weather satellite, from its native 2km resolution down to 250m — closing the gap between sensor resolution and the resolution required by downstream applications such as agriculture and urban monitoring.

동기 및 문제 정의Background & Motivation

GK2A는 한반도 전역을 관측하는 정지궤도 위성이지만 LST 산출물의 해상도(약 2km)는 세밀한 분석에 한계가 있습니다. 자연 이미지 SR 기법을 그대로 적용하면 위성 영상 특유의 sensor noise, 대기 효과, 그리고 GK2A와 가이드 위성(GK2B) 사이의 spectral mismatch를 제대로 다루지 못해 정확도가 떨어집니다.

While GK2A continuously observes the Korean Peninsula, its LST product at ~2km resolution limits fine-grained downstream analysis. Off-the-shelf super-resolution methods designed for natural images fail to handle satellite-specific characteristics — sensor noise, atmospheric effects, and the spectral mismatch between GK2A and the higher-resolution guide sensor (GK2B).

접근 방법Approach

Guided Depth Super-Resolution (GDSR) 관점에서 문제를 재정의하고, 저해상도 GK2A를 고해상도 RGB 가이드 영상(GK2B)으로 안내하는 구조로 설계했습니다.

  • 아키텍처: DCTRRDBNet — DCTNet 기반 + Residual-in-Residual Dense Block + Guided Edge Spatial Attention
  • 센서 간 차이 보정: Difference Learning으로 spectral mismatch 학습
  • 후처리: LightGBM 기반 정확도 향상
  • 업샘플 경로: GK2A(32×32) → ×4(128×128) → ×8(256×256) ≈ GK2B 해상도

We reframed the task as Guided Depth Super-Resolution (GDSR), using the high-res RGB imagery from GK2B to guide the upsampling of low-res GK2A LST.

  • Architecture: DCTRRDBNet — DCTNet-based with Residual-in-Residual Dense Blocks and a Guided Edge Spatial Attention module
  • Cross-sensor calibration: Difference Learning to bridge spectral mismatch
  • Post-processing: LightGBM refinement for further accuracy
  • Upsampling path: GK2A (32×32) → ×4 (128×128) → ×8 (256×256), matching GK2B

과제는 3개 phase로 구성됩니다:

  • Phase 1 — Clear-Sky 다운스케일링. 구름이 없는 조건에서 LST 고해상화. (완료)
  • Phase 2 — Cloud-Sky 처리. 구름의 영향을 받는 상황에서의 LST 고해상화. (진행 중)
  • Phase 3 — All-Sky 통합 모델. Clear/Cloud를 통합하는 단일 모델. (예정)

The work is organized in three phases:

  • Phase 1 — Clear-Sky downscaling. LST super-resolution under cloud-free conditions. (completed)
  • Phase 2 — Cloud-Sky handling. LST super-resolution under cloud-affected conditions. (in progress)
  • Phase 3 — All-Sky unified model. A single model spanning Clear and Cloud regimes. (planned)

진행 상황 및 성과Status & Results

  • Phase 1 (Clear-Sky): 2km → 250m 다운스케일링에서 LST RMSE ≤ 3K, SST RMSE ≤ 2K 달성
  • Phase 2 (Cloud-Sky): 모델 설계 및 학습 진행 중
  • 기상청에 40페이지 이상의 기술 문서 제출 — 데이터 처리, 모델 설계, 평가 절차 포함
  • Phase 1 (Clear-Sky): Achieved LST RMSE ≤ 3K and SST RMSE ≤ 2K on the 2km → 250m task
  • Phase 2 (Cloud-Sky): Model design and training in progress
  • Delivered 40+ pages of technical documentation to KMA, covering data processing, model design, and evaluation

역할My Role

데이터 처리 파이프라인과 모델 설계를 주도하고, 기상청 제출 기술 문서를 작성했습니다. Difference Learning 기반 sensor mismatch 보정 구조를 제안했고, Phase 1 결과 검증을 담당했습니다.

Led the data pipeline and model design, and authored the technical documentation submitted to KMA. Proposed the Difference Learning component for sensor-mismatch correction and validated the Phase 1 results.
